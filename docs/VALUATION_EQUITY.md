## INVESTOR RIGHTS

### Standard Crowdcube Terms

| Right | Included |
|-------|----------|
| Information rights | Annual accounts |
| Pre-emption rights | No (waived on Crowdcube) |
| Tag-along rights | Yes (standard) |
| Drag-along rights | Yes (at 75%+ threshold) |
| Board seat | No |
| Veto rights | No |

### What Crowdcube Investors Get

1. **Equity ownership** — real shares, real upside
2. **Shareholder updates** — quarterly communications
3. **Exit participation** — pro-rata in any exit event
4. **Transfer rights** — can sell on Crowdcube secondary market (limited)

### What Crowdcube Investors Don't Get

1. **Board representation** — operational decisions remain with founders
2. **Veto rights** — can't block future funding rounds
3. **Pro-rata rights** — no guarantee of future round participation
4. **Dividends** — unlikely at this stage (reinvestment priority)

## LEGAL CONSIDERATIONS

### Required Documents

1. **Articles of Association** — ensure compatible with Crowdcube
2. **Shareholders Agreement** — template for Crowdcube investors
3. **Investment Agreement** — Crowdcube provides standard
4. **Due Diligence Pack** — financials, IP ownership, contracts

### Key Legal Points

- **IP Assignment** — ensure all code/IP properly assigned to company
- **Founder vesting** — consider 4-year vesting with 1-year cliff
- **Director duties** — understand obligations to all shareholders
- **Future funding** — Articles should allow for future equity rounds
